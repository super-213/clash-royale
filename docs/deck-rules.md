# 标准卡组规则核对

核对日期：2026-10-13。范围为三个特殊栏位均已解锁的标准八卡组。当前未接入玩家账号的竞技场、卡牌或形态解锁状态；目录中的能力表示该形态存在，玩家应确认实际已解锁。部落战与特殊活动卡组另有规则，当前编辑器不提供这些模式。

## 官方依据与术语

- [卡牌和卡组（官方中文）](https://support.supercell.com/clash-royale/zh_cn/articles/cards-and-decks-6.html)：觉醒栏位、精英栏位、魔法栏位；魔法栏位中的双形态卡可切换觉醒和精英。
- [英雄（Champion）](https://support.supercell.com/clash-royale/zh_cn/articles/champions-10.html)：英雄牌使用精英栏位或魔法栏位，两个栏位均解锁时最多配置两张。
- [精英（Hero）](https://support.supercell.com/clash-royale/zh_cn/articles/heroes-4.html)：基础卡的精英形态，在相应栏位激活。Hero 与 Champion 必须分别译为精英和英雄。
- [2026-03-16 栏位重做](https://supercell.com/en/games/clashroyale/blog/news/mid-march-update/)：标准配置为一个觉醒、一个精英、一个魔法栏位；分别在竞技场 3、5、10 解锁。
- [2026 年 10 月更新（官方中文）](https://support.supercell.com/clash-royale/zh_cn/articles/watts-new-october-2026.html)：本月新形态为精英闪电法师、觉醒雷电巨人。当前能力目录已包含这两种形态。

| 类别            | 觉醒栏位               | 精英栏位               | 魔法栏位                       | 普通栏位   |
| --------------- | ---------------------- | ---------------------- | ------------------------------ | ---------- |
| 基础卡          | 有觉醒则激活，否则普通 | 有精英则激活，否则普通 | 使用可用特殊形态，双形态可切换 | 普通形态   |
| 英雄牌 Champion | 不在此使用             | 可使用                 | 可使用                         | 不在此使用 |

界面沿用用户指定的前三个位置顺序，文字统一使用官方中文名称。卡槽上下方不显示名称标签；辅助标签、提示和形态切换入口使用相同术语。补齐小王子、科学怪哥布林、刺客头领的名称，依据官方英雄表。

## 本站操作约定

官方资料说明栏位资格和形态激活规则；以下自动排位顺序是本站为减少操作步骤制定的交互策略，不声称是游戏客户端的逐步复刻。

1. 空槽点卡直接填入，普通卡的形态随目标栏位决定；满槽替换支持先选卡或先选栏位。英雄牌选中后自动安排，免去再次选合法栏位。
2. 英雄牌优先使用空的合法栏位，再使用未放英雄的合法栏位；同条件优先精英栏位。尽量保留现有特殊形态。
3. 用户指定了普通位置时，将英雄移入合法栏位，原合法栏位的基础卡移入用户指定位置，移走的卡按新位置切换形态。原目标卡被替换，其他卡保留。
4. 两个合法栏位都已有英雄时，新英雄替换指定合法栏位中的英雄；没有指定合法栏位则替换精英栏位中的英雄，明确提示被替换的卡名和两张上限。不会生成三英雄配置，也不额外删除普通卡。
5. 卡组内换位保留八张牌；若换位把英雄移出合法栏位，会自动重新安置。两张英雄已占满合法栏位且换位无法成立时，英雄保持合法位置，不弹出要求玩家手动调整的错误。
6. 基础卡移入觉醒/精英栏位时激活对应能力，移到普通栏位恢复普通形态；移入魔法栏位时保留可用的明确特殊形态，否则默认觉醒优先，再精英。双形态卡在魔法栏位仅提供觉醒/精英切换。没有特殊形态的基础卡保持普通。
7. 每次自动排位、替换、换位或形态切换均作为一次操作，可一步撤销，恢复整套卡牌与形态；搜索、选中和失败操作不消耗撤销。

来源历史记录保持其观测形态，不能按当前目录推测激活状态。自动转换仅作用于用户正在编辑的自配草稿。来源适配时优先安置英雄牌；超过两张英雄的来源无法在保留八张原牌的前提下适配为标准卡组，因此明确报告原因，不擅自换牌。打开旧编辑草稿时按当前栏位整理形态，魔法栏位明确选择的觉醒/精英会保留。
